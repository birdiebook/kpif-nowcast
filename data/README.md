# data/

Innehållet här committas inte. All data hämtas med skripten i `src/` så att
allt är reproducerbart och inga licensvillkor bryts.

- `raw/` – rådata exakt som den hämtades, med hämtdatum i filnamnet
- `vintages/` – ögonblicksbilder av vad som var känt vid ett visst datum (för ärlig backtest)
- `processed/` – rensad och sammanställd data
