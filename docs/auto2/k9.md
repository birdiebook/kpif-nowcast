## PR-text

**K9: längre horisont 3–12 mån – korrektion och krympning av Riksbankens prognos**

- `src/kpif_nowcast/k9_horizon.py`: fyra förregistrerade varianter ovanpå Riksbankens prognos vid prognosdagen:
  ridge-korrektion med nästlad tidsserie-CV (`gap = h`) på h = 3 och h = 12, krympning mot 2 % med skattad vikt
  (h = 12) och "missen består" med en parameter (h = 6). Features = det som hänt sedan Riksbankens cutoff
  (egen miss, ålder, Brent, KIX, räntor, KI-prisplaner, PPI, euroområdets HIKP), allt via `observations.as_of`.
  DM-test med Newey-West lagg h − 1 och Holm. Kör: `python -m kpif_nowcast.k9_horizon`.
- `tests/test_k9_horizon.py`: identisk prognos med och utan data efter prognosdagen för alla fyra varianter,
  startregel, träningsrader, DM/Holm.
- Förregistrering `docs/auto2/k9/hypotes.md`, resultat `docs/auto2/k9/resultat.md`, rådata
  `docs/auto2/k9/results_raw.md`, körlogg i `experiments/runs/`, två rader i beslutsloggen.
- Resultat: ingen variant klarade urvalsskärmen (alla Holm p = 1,00). Riksbanken förblir referens på 3–12 mån;
  på 12 mån är "2 %" lika bra. Inga nya hämtningar, inga nya paket.
